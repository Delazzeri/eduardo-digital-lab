# Eduardo Digital Lab

Site pessoal de página única (one-page) para apresentação profissional: quem sou, projetos, serviços de marketing, certificados, ferramentas, trajetória e contato.

**Live:** [eduardo-digital-lab.vercel.app](https://eduardo-digital-lab.vercel.app)
**Stack:** Vite · React · TypeScript · shadcn/ui · Tailwind CSS

> Projeto pessoal — peça de portfólio.

## Sobre o projeto

Landing page única, dividida em seções: Hero, Sobre, Projetos, Marketing, Certificados, Ferramentas, Timeline, Diferencial e Contato.

## Stack

| Camada     | Escolha           |
| ---------- | ------------------ |
| Build tool | Vite                 |
| Linguagem  | TypeScript            |
| UI         | React + shadcn/ui       |
| Estilo     | Tailwind CSS             |
| Deploy     | Vercel                     |

## Estrutura

```
src/
  components/   # seções da página (Hero, About, Projects, Marketing, ...)
  pages/        # Index e NotFound
  hooks/        # hooks compartilhados
  lib/          # utilitários
```

## Getting started

```bash
npm install
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173).
